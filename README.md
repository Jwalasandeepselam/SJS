# AdaptiveAI — Personalized Learning Platform

A comprehensive, intelligent Python learning game supporting both Vercel Serverless and Streamlit deployments.

## Features
- **Off-White Design Theme (#FAF9F6) & Noto Sans Typography**
- **Brand Logo Header:** 🎮 AdaptiveAI — Personalized Learning
- **Role Selection:** Student, Teacher, and Other accounts
- **Dual Identity Verification:** University Registration Number or University ID Card upload
- **Unique Student IDs (STU-XXXXXX)**
- **Teacher Observation Portal:** Exclusive claims & 3-tier performance categorization (🟢 Performing Well, 🟡 Moderate, 🔴 Needs Intervention)
- **Interactive AI Doubt Clarifier Chatbot:** Real-time doubt resolution on false options
- **Diagnostic & Adaptive Play Loop:** Dynamic difficulty progression & staged hints
- **Python World Skill Map, Analytics Dashboard & Leaderboard**

## Deployment Options

### Option 1: Deploy on Vercel
1. Push this repository to GitHub.
2. Go to [vercel.com/new](https://vercel.com/new) and import the repository.
3. Vercel will automatically read ercel.json and deploy the full-stack app.

### Option 2: Deploy on Streamlit Community Cloud
1. Push this repository to GitHub.
2. Go to [share.streamlit.io](https://share.streamlit.io).
3. Select this repository, set the main file path to pp.py, and click Deploy.

### Option 3: Run Locally
- **Vercel / Flask App:** python api/index.py (Runs on http://localhost:5000)
- **Streamlit App:** streamlit run app.py (Runs on http://localhost:8501)
